# Facebook Page Automation Demo

A responsive, client-facing product demo for a single Facebook Page automation system.

## Preview

Open `dist/index.html` in a browser, or serve the `dist` directory with any static web server.

## Demo features

- Operations overview
- Messenger-style inbox and human takeover
- Order pipeline
- Automation rules and FAQ management
- Shadow/live mode controls
- Responsive desktop and mobile layouts

All data is illustrative and stored only in the browser.
